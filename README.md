# Thermal Properties Visualization

A "meeting room" analogy for how heat spreads through a material: watch an idea pass from person to person as k, ρ, and c_p change.

## Live tool

[Open Thermal Properties Visualization](https://nuhaaljuneidi.github.io/thermal-tool/)

## Features

- Sliders and material presets for thermal conductivity, density, and specific heat.
- Live volumetric heat capacity ρc_p and thermal diffusivity α = k/(ρc_p).
- Animation that shows why a high-diffusivity material responds faster.

## Run locally

Open `index.html` in a modern browser. No build step is needed.
